JustConvertIt — offline file converter

• Works without an internet connection after install
• Does not upload your files or require an account
• Optional tools (LibreOffice / FFmpeg) can be installed later from Settings

Install notes
• Default install needs no administrator password
• After Setup finishes, open JustConvertIt from the Start Menu (or desktop shortcut)
• Windows may warn that the app is unsigned — use More info → Run anyway on a personal PC
• School/work PCs with Application Control may block the app until IT allows it
